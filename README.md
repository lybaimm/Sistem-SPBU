# Sistem-SPBU
Sistem Manajemen Dispenser SPBU berbasis Java CLI (Command Line Interface) untuk Responsi Akhir Praktikum Pemrograman Berorientasi Objek (PBO) Informatika Unsoed — NIM H1D025153. Mengimplementasikan 10 konsep inti OOP (Encapsulation, Inheritance, Abstract Class, Polymorphism, &amp; Multiple Interface).
